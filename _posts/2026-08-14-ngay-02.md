## 1. Class

### 1.1. Định nghĩa

`class` (lớp) là một khuôn mẫu; `instance` (đối tượng) là một thực thể được tạo ra từ khuôn mẫu đó.

Khi cần khởi tạo thuộc tính riêng cho từng đối tượng, ta sử dụng phương thức `__init__()`:

```python
class Human:
    gender = "male"  # Thuộc tính của class, được các instance dùng chung

    def __init__(self, name: str, age: int) -> None:
        self.name = name  # Thuộc tính riêng của instance
        self.age = age


person_1 = Human("Quang", 20)

print(person_1.name)  # Quang
print(person_1.age)   # 20
```

Trong ví dụ trên:

| Thành phần | Ý nghĩa |
|---|---|
| `Human` | Tên class |
| `person_1` | Một instance của class `Human` |
| `gender` | Class variable, được các instance dùng chung |
| `name`, `age` | Instance variable, thuộc riêng từng instance |
| `self` | Tham chiếu đến instance hiện tại |

### 1.2. Inheritance

`inheritance` (kế thừa) cho phép một lớp con nhận lại các thuộc tính và phương thức từ lớp cha. Nhờ đó, ta có thể tái sử dụng mã nguồn và mở rộng tính năng dễ dàng hơn.

Khi cần gọi hoặc mở rộng logic của lớp cha, ta dùng `super()`:

```python
class Student(Human):
    def __init__(self, name: str, age: int, grade: int) -> None:
        super().__init__(name, age)
        self.grade = grade


student_1 = Student("Hoang", 18, 12)

print(student_1.name)   # Hoang — kế thừa từ Human
print(student_1.grade)  # 12 — thuộc tính riêng của Student
```

Một class cũng có thể kế thừa từ nhiều class:

```python
class Flyable:
    def fly(self) -> str:
        return "Đang bay"


class Swimmable:
    def swim(self) -> str:
        return "Đang bơi"


class Duck(Flyable, Swimmable):
    pass


duck = Duck()

print(duck.fly())   # Đang bay
print(duck.swim())  # Đang bơi
```

> Khi dùng đa kế thừa, thứ tự tìm kiếm thuộc tính và phương thức được xác định bởi MRO (Method Resolution Order). Có thể xem thứ tự này bằng `Duck.mro()`.

## 2. Typing

Type hint mô tả kiểu dữ liệu mà một biến, tham số hoặc giá trị trả về được mong đợi sử dụng. Nó giúp code dễ đọc hơn và cho phép các công cụ như mypy phát hiện một số lỗi kiểu dữ liệu trước khi chạy chương trình.

> Type hint không tự ép kiểu và thường không ngăn chương trình chạy. Muốn kiểm tra tĩnh, cần dùng công cụ như mypy.

### 2.1. Type hint cơ bản

Khai báo kiểu cho biến:

```python
name: str = "An"
age: int = 20
score: float = 8.5
active: bool = True
```

Khai báo kiểu cho tham số và giá trị trả về của hàm:

```python
def calculate_score(value: float, weight: float) -> float:
    return value * weight
```

Trong đó:

- `value: float` và `weight: float` là kiểu mong đợi của các tham số.
- `-> float` là kiểu dữ liệu mà hàm dự kiến trả về.

### 2.2. Kiểu collection

Có thể chỉ rõ cả kiểu collection và kiểu của phần tử bên trong:

```python
names: list[str]
scores: dict[str, float]
coordinates: tuple[float, float]
unique_skills: set[str]
```

| Type hint | Ý nghĩa |
|---|---|
| `list[str]` | Danh sách các chuỗi |
| `dict[str, float]` | Dictionary có key là `str`, value là `float` |
| `tuple[float, float]` | Tuple gồm hai số thực |
| `set[str]` | Tập hợp các chuỗi không trùng lặp |

Ví dụ:

```python
def average(scores: list[float]) -> float:
    return sum(scores) / len(scores)
```

### 2.3. Union và `None`

Dùng toán tử `|` khi một giá trị có thể thuộc nhiều kiểu:

```python
def parse_value(text: str) -> int | float:
    if "." in text:
        return float(text)
    return int(text)
```

Dùng `| None` khi một giá trị có thể không tồn tại:

```python
def find_user(user_id: int) -> str | None:
    users = {1: "An", 2: "Binh"}
    return users.get(user_id)
```

Khi gọi `find_user(3)`, hàm trả về `None` vì không tìm thấy người dùng có ID tương ứng.

## 3. Pytest

Pytest là một framework giúp viết và chạy các bài kiểm thử tự động cho chương trình Python.

### 3.1. Bắt đầu với pytest

Nếu thư mục hiện tại chưa phải là một dự án uv, hãy khởi tạo dự án trước:

```powershell
uv init
```

Sau đó cài pytest dưới dạng dependency dùng trong quá trình phát triển:

```powershell
uv add --dev pytest
```

Tạo file `tests/test_calculator.py`:

```python
def add(a: int, b: int) -> int:
    return a + b


def test_add() -> None:
    assert add(2, 3) == 5
```

Chạy test:

```powershell
uv run pytest
```

Theo quy ước mặc định, pytest tự động tìm:

- File có tên `test_*.py` hoặc `*_test.py`.
- Hàm có tên bắt đầu bằng `test_`.
- Class có tên bắt đầu bằng `Test` và không định nghĩa `__init__()`.

Nếu biểu thức `assert` đúng, test **pass**; nếu sai, test **fail**.

### 3.2. Cấu trúc một test

Một test thường có ba phần: **Arrange – Act – Assert**.

```python
def test_calculate_total() -> None:
    # Arrange: chuẩn bị dữ liệu
    price = 10.0
    quantity = 3

    # Act: chạy code cần kiểm tra
    result = price * quantity

    # Assert: kiểm tra kết quả
    assert result == 30.0
```

| Phần | Mục đích |
|---|---|
| Arrange | Chuẩn bị dữ liệu và điều kiện cần thiết |
| Act | Gọi đoạn code cần kiểm tra |
| Assert | So sánh kết quả thực tế với kết quả mong đợi |

Mỗi test nên kiểm tra một hành vi rõ ràng và không phụ thuộc vào test khác.

Tên test nên mô tả hành vi được kiểm tra:

```python
def test_normalize_name_removes_surrounding_spaces() -> None:
    ...
```

### 3.3. Cách chạy test

| Lệnh | Công dụng |
|---|---|
| `uv run pytest` | Chạy toàn bộ test |
| `uv run pytest -v` | Hiển thị tên và trạng thái của từng test |
| `uv run pytest -q` | Hiển thị output ngắn gọn |
| `uv run pytest tests/test_validation.py` | Chạy test trong một file |
| `uv run pytest tests/test_validation.py::test_rejects_empty_name` | Chạy một test cụ thể |
| `uv run pytest -k empty` | Chạy các test có tên chứa `empty` |
| `uv run pytest -x` | Dừng ngay khi gặp lỗi đầu tiên |

## 4. Tóm tắt kiến thức cần nhớ

- Class là khuôn mẫu; instance là đối tượng được tạo ra từ class.
- `__init__()` dùng để khởi tạo trạng thái ban đầu của một instance.
- Class variable được dùng chung; instance variable thuộc riêng từng instance.
- Kế thừa giúp tái sử dụng và mở rộng code; dùng `super()` để gọi logic của lớp cha.
- Type hint giúp code dễ hiểu và hỗ trợ công cụ kiểm tra kiểu như mypy.
- Dùng `|` để biểu diễn nhiều kiểu có thể có và `| None` cho giá trị có thể không tồn tại.
- Pytest tự tìm các file và hàm test theo quy ước đặt tên.
- Một test nên có cấu trúc Arrange – Act – Assert và chỉ kiểm tra một hành vi rõ ràng.
- Có thể dùng `-v`, `-q`, `-k` và `-x` để điều chỉnh cách chạy pytest.
